# 10A06 — Nhóm 2

Website giới thiệu Nhóm 2 của lớp 10A06.

## Công nghệ
HTML5 · CSS3 · JavaScript thuần · Google Fonts.

## Chạy local
Mở `index.html` trong trình duyệt hoặc dùng Live Server.

## Tuỳ chỉnh
Thay tên thành viên, vai trò, email và nội dung dự án trong `index.html`.

## GitHub Pages
Vào **Settings → Pages**, chọn **Deploy from a branch**, branch `main`, folder `/ (root)` rồi lưu.
